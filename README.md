# Nimble Bear

Unofficial, free Nimble 2 character sheet extension for [Owlbear Rodeo](https://www.owlbear.rodeo). Not affiliated with Nimble Co. or Owlbear Rodeo.

This app is free to use for anyone who already owns the content, is trying the system out, or cannot afford to buy it right now. If you enjoy Nimble and are able, please support the game by purchasing the official content at nimbleRPG.com.

Nimble Bear is an independent product published under the Nimble 3rd Party Creator License. Nimble © Nimble Co.

## Install in Owlbear Rodeo
In your Owlbear profile, choose **Add Extension** and paste:

```
https://krunklewitz.github.io/nimble-bear/manifest.json
```

Then enable it for a room. Desktop Chrome is the supported browser.

## Development
Node (see `.nvmrc`), then `npm install`. `npm run dev` serves on http://localhost:5173 (manifest at `/manifest.json`). `npm run check` runs typecheck, lint, tests and build.
